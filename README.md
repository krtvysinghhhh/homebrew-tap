# Homebrew Tap for Orvpass

Official Homebrew tap for [Orvpass](https://github.com/krtvysinghhhh/Orvpass) — ultra-fast, zero-knowledge terminal password & secrets manager in pure Rust.

## Installation

```bash
brew tap krtvysinghhhh/tap
brew install orvpass
```

Or install in a single command:

```bash
brew install krtvysinghhhh/tap/orvpass
```

## Updating

```bash
brew update
brew upgrade orvpass
```

## Documentation

Full documentation, CLI manual, and source code are available at [github.com/krtvysinghhhh/Orvpass](https://github.com/krtvysinghhhh/Orvpass).
